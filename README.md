# AMOO TECH

A fictional technology and electronics store built as a frontend portfolio project with HTML5, CSS3 and vanilla JavaScript. No frameworks.

> **Demo notice:** AMOO TECH, its products, prices, reviews, address, phone and email are fictional. Checkout and the newsletter are demonstrations: no payments are processed and no data is collected or sent.

## Features
- Responsive header, mobile menu, live cart count, header search
- 12 demo products (NGN) with category filter, name search, sorting (price, newest) and availability filter, all combined
- Product details modal with specs and quantity selector
- Cart drawer: add, remove, increase, decrease, clear, subtotal and total, saved in LocalStorage
- Validated checkout demo with generated order reference
- Validated newsletter demo, deals, about, labelled sample reviews, contact, footer

## Run
Open `index.html` in a browser (internet needed for photos and fonts; fallback graphics show if an image fails).

## Structure
`index.html` · `css/style.css` · `js/products.js` (data) · `js/cart.js` (cart + storage) · `js/script.js` (UI)

## Limitations
- Product photos are hotlinked from Unsplash; replace them with files in `assets/images/` for production.
- No backend, accounts, real payments or order storage.
- Social links are demo placeholders.
